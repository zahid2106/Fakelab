# Al-Shazaib Lab APK
1. Create a new GitHub repository and upload everything in this folder (keep the .github folder).
2. Open the Actions tab -> "Build APK" -> Run workflow (it also runs on every push to main).
3. When it finishes (about 5 minutes), open the run and download the "Al-Shazaib-Lab-APK" artifact.
4. Unzip it and install app-debug.apk on the phone (allow "install unknown apps").
Patient data is stored on the phone. Use Backup / Restore inside the app to keep a copy.
